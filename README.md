## 几个常见问题

**Q：恒创的活动价格会一直有效吗？**
活动有期限，但恒创的"续费同价"政策是长期的——首年活动价，续费保持不变。活动本身可能调整，但已经下单的订单续费不受影响。

**Q：香港一区和二区怎么选？**
一区只有BGP精品线路（CN2），价格高但回国延迟最低（10ms）；二区有BGP精品/优化/国际/高防四种线路，选择多，优化线路性价比高。对延迟敏感选一区，对价格敏感选二区优化线路。

**Q：云服务器支持Windows吗？**
支持Windows Server 2012/2016/2019/2022全版本，但2核2G及以上配置才建议装Windows，1核1G跑Windows容易卡。

**Q：能不能先试用？**
恒创有免费试用政策，部分产品支持试用，具体可以咨询在线客服。轻量云支持3天无理由退款，相当于变相试用。

**Q：原生IP和非原生IP有什么区别？**
日本节点默认开通非原生IP，原生IP限量供应需额外联系客服。原生IP对某些业务（比如需要日本本地IP识别的服务）更友好，普通业务非原生IP够用。
